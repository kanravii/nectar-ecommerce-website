# nectar-ecommerce-website
## About the Project
This is a front-end e-commerce website developed as a final project for ITE120.

The Nectar website is drinks online shopping, which are designed to provide users with an easy and convenient online shopping experience.

## Project Features
- User-friendly interface
- Product display
- Shopping interface
- Website navigation
- Creating Account

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Type
University Final Group Project

## Course
ITE120
